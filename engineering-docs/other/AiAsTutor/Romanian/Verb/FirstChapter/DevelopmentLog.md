# Development Log: First Chapter - Romanian Verbs

## Project Context
This folder (`FirstChapter`) is part of an ongoing exploration into using LLMs to create a digital tutor for primary school children. The focus here is on introducing fundamental Romanian grammar concepts (specifically verbs) to an English-speaking primary student who knows some basic Romanian words and nominative pronouns.

## Approach & Design Principles
- **Self-Contained Files**: All HTML files are strictly self-contained with no external CSS, JavaScript, or image dependencies to make them easily portable.
- **Kid-Friendly Aesthetics**: The design uses modern web aesthetics (vibrant color gradients, rounded fonts like 'Nunito', glassmorphism, and emojis) to engage the student.
- **Intuitive Mapping**: Romanian grammar structures are mapped to their closest English equivalents using color-coded highlighting to drive intuition (e.g., mapping `Eu am făcut` to `I have done`).
- **Print Economy**: Every HTML file includes dedicated `@media print` CSS rules. These rules remove heavy background colors and box-shadows to save ink, reformats grid layouts (e.g., ensuring 2-column fits on A4 paper), and uses simple borders instead of solid color blocks for highlighting.

## Files Developed

### 1. `RomanianVerbsPresentation_0.html`
- **Purpose**: The introductory lesson.
- **Content**: 
  - Quick recap of pronouns (Eu, Tu, El/Ea, etc.).
  - Introduces the "Infinitive" (the name of the verb).
  - Explains the **Present Tense** (using *a face*).
  - Explains the **Past Tense** using the auxiliary *a avea* + participle (e.g., *Eu am făcut* / *I have done*).
  - Explains the **Future Tense** using the auxiliary *a voi* + infinitive (e.g., *Eu voi face* / *I will do*).

### 2. `RomanianVerbsPresentation_1.html`
- **Purpose**: A reference sheet / flashcards for the most common verbs.
- **Content**: Features an aesthetically pleasing grid of 16 essential verbs: *a fi, a avea, a vrea, a merge, a pleca, a face, a fugi, a putea, a vorbi, a scrie, a citi, a mânca, a bea, a veni, a ști, a vedea*.
- **Structure**: Each verb card was iteratively condensed to show the Infinitive, the Participle, the Present Tense conjugations (ordered in two columns: singular and plural), and a 3-4 word usage example sentence with an English translation.
- **Print Layout**: Optimizes perfectly into two side-by-side columns for an A4 Landscape printout.

### 3. `generate_exercises.py`
- **Purpose**: A Python script created to procedurally generate practice exercises to avoid hallucination and manual typing limitations. 
- **Content**: Defines the vocabulary (the 16 verbs, conjugations, and complements) and randomly samples them to generate diverse sentences in the present, past, and future tenses.

### 4. `Exercises_1.html`
- **Purpose**: The practice worksheet.
- **Content**: Generated by the Python script, it contains exactly 100 fill-in-the-blank translation exercises. 
- **Structure**: The student is given an English sentence (e.g., *I have a dog.*) and must fill in the blanks for the Romanian verb forms (e.g., *Eu ___ un câine.*). Blanks represent the exact number of words needed (e.g., 2 blanks for past tense auxiliaries + participles).
- **Print Layout**: Configured for an A4 Portrait printout with two columns of exercises.

### 5. `generate_exercises_2.py`
- **Purpose**: Procedural generator script for the second set of verb exercises.
- **Content**: Reuses the exact same seed (42) and vocabulary structure to generate 140 unique exercises, slicing the last 40 non-overlapping exercises.

### 6. `Exercises_2.html`
- **Purpose**: The second practice worksheet.
- **Content**: Contains 40 more unique fill-in-the-blank translation exercises (numbered 101 to 140) ensuring no overlap with the first worksheet.
- **Print Layout**: Optimizes perfectly for A4 Portrait printout with two columns.

### 7. `RomanianNumeralsPresentation.html`
- **Purpose**: The introductory lesson for numerals.
- **Content**:
  - Cardinal numbers from 0 to 10.
  - Explains the **Gender Split** for 1 (*un/o*, *unu/una*) and 2 (*doi/două*) and how Copycat Nouns (neuters) copy boys in the singular and girls in the plural.
  - Explains the **Teen Equation** using `unit + spre + zece` (e.g., *treisprezece*) and highlights irregular mutations (*unsprezece*, *doisprezece/douăsprezece*, *paisprezece*, *șaisprezece*).
  - Explains **Tens** using `-zeci` and the connector **și** (e.g., *douăzeci și cinci*).
  - Explains **Hundreds** (*o sută / sute*), **Thousands** (*o mie / mii*), and **Millions** (*un milion / milioane*).
  - Features the **Magic "DE" Rule**:
    - Numbers ending in 1-19: NO *de* (*cinci mere*, *cincisprezece mii*).
    - Numbers ending in 20+: YES *de* (*douăzeci de mere*, *o sută de mii*, *douăzeci de milioane*).
- **Print Layout**: Configured for an A4 Landscape printout with dual columns and high-contrast outline borders.

### 8. `generate_numerals_exercises.py`
- **Purpose**: Procedural Python generator script for the numerals chapter.
- **Content**: Implements a complete number-to-text algorithm for Romanian numerals (up to 99,999,999) with full gender noun agreements and preposition "de" triggers. Procedurally outputs a balanced mix of 100 exercises spanning units, teens, tens, hundreds, thousands, and millions.

### 9. `Exercises_Numerals.html`
- **Purpose**: The numerals practice worksheet.
- **Content**: Features 100 randomized translation exercises. Each card splits the target Romanian numeral phrase into exact word blanks (e.g., 4 blanks for *douăzeci și două de*), allowing the student to practice spelling and preposition insertion perfectly.
- **Print Layout**: Highly optimized for A4 Portrait printout with dual columns and ink-saving designs.

### 10. `exercises_numerals_solutions.json`
- **Purpose**: Solution manifest.
- **Content**: A complete JSON listing of all generated exercise numbers, English sentences, Romanian sentence skeletons, and correct target solutions for verification and grading.

### 11. `RomanianOrdinalNumeralsPresentation.html`
- **Purpose**: A concise presentation focusing on Ordinal Numerals.
- **Content**: 
  - Introduces the irregular forms for 1st (*primul/prima*).
  - Explains the "Sandwich" formula for masculine/neuter (`al ... lea`) and feminine (`a ... a/ea`).
  - Provides a complete reference for numbers 2-10 across both genders.
  - Demonstrates how the formula applies to compound numbers beyond 10 (*al unsprezecelea*, *a douăzeci și una*).
- **Print Layout**: Optimizes with ink-saving variables and forces the grid to display efficiently when printed.

### 12. `SecondChapter/RomanianVerbsGroupsPresentation_0.html`
- **Purpose**: Lesson presentation on Romanian verb classifications.
- **Content**:
  - Introduces the four verb conjugations (families) based on infinitive endings (-a, -ea, -e, -i/-î).
  - Places the 16 primary verbs learned in FirstChapter into their respective castles, including classifying *a bea* in Kingdom II.
  - Features an interactive click-to-sort challenge game with automated progress tracking and canvas-based victory confetti.
- **Print Layout**: Optimizes for A4 portrait printing, hiding game elements and providing clean outline borders.

### 13. `SecondChapter/RomanianVerbsGroupsPresentation_1.html`
- **Purpose**: Deep-dive lesson presentation on Romanian Conjugation I (ending in `-a`) verbs.
- **Content**:
  - Introduces 8 new common verbs in the `-a` family: *a cânta*, *a juca*, *a lucra*, *a asculta*, *a cumpăra*, *a dansa*, *a întreba*, *a chema*.
  - Explains the two present tense paths: Regular (no suffix, e.g. *a cânta*) and Suffix (using the *-ez* suffix, e.g. *a lucra*), noting that *Noi* and *Voi* are suffix-free.
  - Explains the past participle construction (drop `-a`, add `-at`) and its usage in the past tense.
  - Displays beautiful reference sheets/flashcards for all 8 new verbs.
  - Includes a fully interactive conjugation/participle quiz with progress tracking and custom canvas-based victory confetti.
- **Print Layout**: Optimizes for A4 portrait printing, hiding the interactive quiz and displaying clean, structured grids and lists.

### 14. `SecondChapter/generate_exercises_1.py`
- **Purpose**: Procedural generator for Conjugation I exercises.
- **Content**: A python script holding a dataset of 10 Conjugation I verbs and their tense-neutral complements. It randomly selects verb, person, complement, and tense (past, present, future) to generate 100 unique Romanian-to-English translation and fill-in-the-blank practice sentences.

### 15. `SecondChapter/Exercises_1.html`
- **Purpose**: A printable practice worksheet containing 100 randomly generated exercises.
- **Content**: Built procedurally by the script above. Tests translation mapping and conjugation memory for Group 1 verbs. Includes a printer-optimized CSS layout.

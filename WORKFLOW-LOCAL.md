# Local Workflow: AI Learning

## Integration Branch

`main`. This project uses single-stream workflow. The parent DevCapsule
repository routes its submodule registration through `sample-projects`.

## Version Scheme

Semantic versioning in `package.json`, initially 0.1.0. Change with
`npm version <version> --no-git-tag-version` only on owner direction.

## Release Policy

No release or deployment is authorized. The owner chooses release and hosting
policy before the first publication intended for end users. The canonical remote is
`git@github.com:ccozianu/ai-learning-bootstrap.git`, supplied by the owner.

## Validation Commands

Environment: Node >=22.12 <23 and npm inside the pinned DevCapsule base.
Run all commands at this repository's root.

- Install: `npm ci`.
- Gate: `npm run check` (Prisma generation, strict TypeScript, frontend build,
  authentication tests with mocked persistence). Future GCP/IAP/GCIP edge tests
  must use deterministic offline JWT/tenant test doubles (never provision live
  cloud projects or local DB containers during automated checks).
- UI integration: `npm run test:ui`; Chromium required (`npx playwright install
  chromium` if absent; or set `PLAYWRIGHT_CHROMIUM_EXECUTABLE` to an installed
  Chromium executable and install ffmpeg with `npx playwright install ffmpeg`). Recorded desktop and mobile tests use a Vite process and
  mocked API replies. They are not live identity-provider acceptance.
- SQL artifact: `npm run db:sql` then review the SQL diff; no database required.
- Live end-to-end: owner applies the SQL and supplies local Google/SMTP/database
  settings, then verifies allowlisted and rejected Google signup, local-password
  confirmation, remembering/forgetting browsers and REST/GraphQL current-user
  access. Record exact environment and outcome without secrets.
- Smoke: `npm run dev` with local settings, then verify `/api/health`, the login
  page and an authenticated `/api/me`. No credentials are needed for UI-only
  preview with `npx vite --host 127.0.0.1`.

## Host Capabilities

VSCodium (`frontend-ide`) is the requested IDE, selected locally through
DevCapsule. PostgreSQL is an externally supplied service. Do not provision
containers or expose host services as a side effect of tests. Agent selection
is a developer-local choice. The shared lock is generated by the rc2 CLI.

## Credential Boundary

Never read or print real credentials, entire environment blocks, connection
strings, OAuth tokens, cookies, confirmation codes or mail transport errors in
agent tool output. No secrets enter Git. The human supplies process environment
in their own capsule terminal. `.env.example` contains names and placeholders
only; `.env` is not automatically loaded. Local scripts consume credentials
without shell interpolation and suppress raw service errors. Do not apply a
schema or send live email without a user-directed acceptance step.

## Design & Planning Gate

- **Overview alignment required before implementation:** Feature implementation
  must not begin without consulting and conforming to the accepted
  [Project Elements Overview](engineering-docs/project-elements-overview.md) and
  its sub-documents (`engineering-docs/overview/`). Update those documents
  whenever core requirements, schema boundaries, or architectural constraints
  change.
- **Coding-agent child-LLM rule:** Coding agents authoring this project must
  **not** generate code that exposes LLM endpoints directly to child accounts
  (nor route child text/prompts to commercial `<18`-banned APIs such as
  Gemini/Vertex, even in batch mode). Any future student-facing AI feature
  (`tutor`, Design Recipe `pair-programmer`, or `FREE_FORM_PROOF` evaluation
  via self-hosted `vLLM` or Anthropic's minors-compliant API) requires explicit
  owner direction and a formal security review first.

## Bootstrap Exception

The owner explicitly requested creation of this independent child project
while working in the parent. Its first local commit may be on `main`; initial publication to the owner-supplied empty remote and the reachable
submodule pointer complete the bootstrap delivery.
This exception ends with the first bootstrap delivery.
